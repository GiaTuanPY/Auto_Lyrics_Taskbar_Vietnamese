# Auto_Lyrics_Taskbar_Vietnamese
🎵 Hiển thị lời bài hát đang phát trực tiếp trên taskbar Windows. Hỗ trợ tự động cập nhật lyrics theo bài hát hiện tại, giúp bạn dễ dàng theo dõi lời nhạc mà không cần chuyển cửa sổ.
## Install - Cài Đặt:
* Yêu cầu Windhawk: https://windhawk.net/

* Tạo extension:

       Edge: edge://extensions/

       Chrome://extensions/

      ... sau đó bật development mode -> load unpacked -> extension/ manifest.json, content.js, background,json
